## Safety Rules

The skill is read-only by default. It requires explicit approval before profile
writes, listing submissions, photo uploads, review replies, product/service
changes, paid ads, or bulk imports.

It rejects fake reviews, review gating, fake branches, virtual-office spam,
keyword-stuffed names, hidden schema facts, invented prices, unsupported claims,
and ranking/indexing guarantees.

This is not an official Google, Yandex, or 2GIS project.
