# Security

This repository contains an agent skill made of instructions and reference
files. It does not need secrets.

Do not add passwords, cookies, OAuth tokens, private keys, business account
exports with private fields, or screenshots containing sensitive account data.

For Google Business Profile, Яндекс Бизнес, 2GIS, Maps, and directory work,
use owner-controlled accounts and official platform flows. Do not automate
login, 2FA, SMS, mail, video verification, or ownership checks through cloud
browsers.
